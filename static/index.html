Real change, luck, or injury?

Ask why a pitcher got better or worse. A Lead splits the question, Researchers query 2.1M pitches in parallel, it goes back for what's missing, and a Writer turns it into a report where every number links to the query that produced it, checked by code and a Critic.

For
Fantasy managers, bettors, analysts and fans deciding whether a pitcher's breakout or slump will last.
How
Name a pitcher and what changed, or pick an example. A vague question gets a follow-up question first. A run takes 1.5–3 minutes, and the report appears as it’s written; click any [Q#] to see the rows and source behind a number. Then ask a follow-up to go deeper: the team remembers the conversation.
Can't
Stuff+, xFIP or SIERA, medical details, mechanics, the minors or the postseason. Pitch-level data starts in 2024. If a question needs any of these, the agent says so.
